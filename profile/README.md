## About

Dopamind is a home for experiments, tools and open-source
projects at the intersection of artificial intelligence and
software engineering.

We build to understand.

We experiment to learn.

We open-source what may help others.

## What We Explore

| Area | Focus |
|---|---|
| AI Systems | LLM applications, reasoning systems and AI infrastructure |
| Agents | Autonomous and semi-autonomous software agents |
| Developer Tools | Tools that improve how software is built and understood |
| Systems | Infrastructure, deployment and developer platforms |
| Experiments | Research prototypes and technical exploration |
